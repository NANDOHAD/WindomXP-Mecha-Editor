# WindomXP-Mecha-Editor

## 日本語

このリポジトリは、[WindomXP-Mecha-Editor](https://github.com/MugenAttack/WindomXP-Mecha-Editor)の日本語化と機体MOD編集機能の拡張を行うプロジェクトです。Test Playをベースに、将来的に原作をUnity上で再現した独立クローンゲームへ発展させることを目指します。既存データの互換性を維持します。

対象Unityは **6000.6.0f1**（2026-09-05決定）。移行・検証状況は [DEV_STATE.md](DEV_STATE.md)、開発資料は [PROJECT_REFERENCE.md](docs/PROJECT_REFERENCE.md)、改善課題は [監査報告](docs/PROJECT_AUDIT_2026-09-05.md) を参照してください。

## English

This project extends and localizes [WindomXP-Mecha-Editor](https://github.com/MugenAttack/WindomXP-Mecha-Editor) into Japanese while preserving existing mech data compatibility. Test Play is being developed as the foundation for a future standalone Unity game recreating the original WindomXP.

The target editor is **Unity 6000.6.0f1**, decided on September 5, 2026. See [DEV_STATE.md](DEV_STATE.md) for migration and validation status; the target version does not imply that migration has passed validation.
