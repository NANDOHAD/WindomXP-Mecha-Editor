If the weapon requires more than 5 data, start with RunProc2, and if it does not exceed 5, you can do whatever you want.
The second label of a weapon is the code name of the weapon, and the first is used to remember how many weapon sentences have been written to oneself. The position data of some weapons is 0 and the meaning is not marked because it has no effect, but some have not been tested. If you are interested, you can try it yourself. Maybe it will be useful.
If the weapon starts from a certain position and the data is all 0, you can omit those along with the comma.
